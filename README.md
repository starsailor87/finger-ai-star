# RFP Insight AI

나라장터 금융 공공기관 IT 입찰공고 모니터링과 RFP 분석을 돕는 서비스입니다. 핑거 AX 해커톤 2차 출품작이며, 현재는 데모 버전으로 계속 업데이트 중입니다.

## 모니터링 대상 (데모)

한국은행, 예금보험공사, 신용보증기금, 기술보증기금, 한국주택금융공사, IBK기업은행, 한국산업은행 — 이후 시중은행으로 확대합니다.

## 로드맵

- **현재(데모):** 서비스 기획, 대상 기관 선정, 데모 화면, GitHub·Vercel 구성
- **1단계 — 공고 자동 수집:** 데일리로 확인하는 공고를 자동 수집하고 시중은행 공고까지 확대
- **2단계 — RFP 분석·리스크 검증:** RFP 업로드 시 AI가 핵심 항목을 요약하고 리스크까지 검증
- **3단계 — 일정 캘린더:** 공고·제안 마감 일정을 캘린더로 한눈에 확인

## 구조
