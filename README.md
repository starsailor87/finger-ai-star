# RFP Insight AI

금융기관 IT 입찰공고를 매일 모니터링하고, RFP를 분석해 리스크까지 검증하며, 일정을 캘린더로 한눈에 보여주는 영업 지원 서비스입니다. 핑거 AX 해커톤 2차 출품작입니다.

## 주요 기능

| 화면 | 주소 | 내용 |
| --- | --- | --- |
| 공고 모니터링 | `#notices` | 마감 임박순 공고 목록, 공공 금융기관/시중은행·유형 필터, 검색·정렬, 공고별 판단 지표와 상세 패널 |
| RFP 분석 | `#analyze` | PDF·TXT 업로드 또는 붙여넣기 → 핵심 항목 추출, 리스크 12종 검증(근거 문장 포함), 역량 키워드 매칭, Go / 검토 필요 / No-Go |
| 일정 캘린더 | `#calendar` | 공고 게시·설명회·제출 마감 월간 캘린더, 14일 일정 목록 |
| 서비스 소개 | `#about` | 서비스 개요, 대상 기관, 로드맵 |

바로 체험: **RFP 분석 → ‘샘플 RFP 불러오기’**

> 화면의 공고와 RFP는 기능 시연을 위한 가상 샘플 데이터이며, 실제 나라장터 공고가 아닙니다. 날짜는 접속한 날을 기준으로 계산됩니다.

## 모니터링 대상

한국은행, 예금보험공사, 신용보증기금, 기술보증기금, 한국주택금융공사, IBK기업은행, 한국산업은행 — 이후 시중은행으로 확대합니다.

## 구조

```
index.html              화면 (해시 라우팅 4개 뷰)
assets/analyzer.js      RFP 분석 엔진 — 항목 추출, 리스크 검증 규칙, 판단 지표 (브라우저·Node 공용)
assets/data.js          가상 샘플 공고·RFP
assets/app.js           화면 로직 (모니터링, 분석, 캘린더, 상세 패널)
assets/styles.css       스타일 (라이트/다크, 모바일 대응)
tests/analyzer.test.js  분석 엔진 단위 테스트
docs/                   발표자료 PDF, 프로젝트 설명
```

빌드 없이 정적 파일로 동작합니다. PDF 텍스트 추출은 pdf.js(cdnjs)를 필요할 때만 불러옵니다.

## 실행과 테스트

```bash
python3 -m http.server 8000   # http://localhost:8000
node --test tests/*.test.js   # 분석 엔진 테스트
```

## 리스크 검증 규칙

제출 마감 임박, 지체상금률, 추가 비용 없는 과업 변경, 공동수급 제한, 하도급 제한, 무상 유지보수·하자보수 기간, 산출물·소스코드 권리 귀속, 인력 상주 요구, 수행 실적 요건, 사업 기간 대비 규모, 가격 평가 비중, 보안 요구사항.

판단 지표(0~100)는 리스크 수준과 역량 키워드 일치도로 계산한 참고값이며, 최종 결정은 담당자가 합니다.

## 로드맵

- **현재(MVP):** 공고 모니터링 화면, RFP 분석·리스크 검증 엔진, 일정 캘린더
- **1단계 — 공고 자동 수집:** 데일리 공고 자동 수집, 시중은행 공고까지 확대
- **2단계 — AI 분석 고도화:** LLM 연동 RFP 요약, 리스크 검증 규칙 확장
- **3단계 — 일정 관리 확장:** 업무 캘린더 연동, 마감 리마인드

## 배포

`main` 브랜치에 push하면 Vercel이 자동으로 배포합니다.
