## RFP Insight AI

**금융 공공기관 IT 입찰공고, 놓치지 않고 빠르게 읽는다**

나라장터에 올라오는 금융 공공기관의 IT 사업 공고를 매일 모니터링하고, 제안요청서(RFP)의 핵심 내용을 AI가 요약·분석해 영업 담당자가 참여 여부를 빠르게 판단하도록 돕는 서비스입니다.

### 해결하려는 문제
- 영업 담당자가 나라장터와 기관별 사이트를 매일 직접 돌며 새 공고를 확인해야 합니다.
- 재공고·정정공고는 눈에 잘 띄지 않아 대응 타이밍을 놓치기 쉽습니다.
- 긴 RFP에서 범위·예산·자격·평가 기준을 찾아 참여 여부를 정하기까지 시간이 오래 걸립니다.

### 대상
- **사용자:** 공공 금융기관 사업을 담당하는 SI·솔루션 영업 담당자
- **모니터링 기관(데모):** 한국은행, 예금보험공사, 신용보증기금, 기술보증기금, 한국주택금융공사, IBK기업은행, 한국산업은행 → 이후 시중은행으로 확대

### 주요 기능
1. **공고 모니터링** — 대상 기관의 나라장터 IT 공고를 데일리로 수집하고 신규·재공고·정정을 구분해 보여줍니다.
2. **RFP 분석** — 업로드한 RFP에서 사업 범위, 예산, 일정, 자격 요건, 평가 기준을 추출해 요약하고 리스크를 검증합니다.
3. **참여 판단 지원** — 자사 역량과 비교해 검토 포인트와 리스크, 다음 할 일을 정리합니다. 최종 결정은 담당자가 합니다.

### 구성
나라장터 공고 → 데일리 수집 → 로컬 저장 → AI 분석 → 웹 화면. 웹 화면은 GitHub `main` 브랜치에 push하면 Vercel로 자동 배포됩니다.

### 진행 상황과 로드맵
현재는 **데모 버전**이며, 계속 업데이트해 나갈 예정입니다.
- **현재(데모):** 서비스 기획, 공공 금융기관 7곳 선정, 데모 화면 구현, GitHub·Vercel 구성
- **1단계 — 공고 자동 수집:** 데일리로 확인하는 공고를 자동으로 수집하고, 공공 금융기관뿐 아니라 시중은행 공고까지 대상을 넓힙니다.
- **2단계 — RFP 분석·리스크 검증:** RFP를 업로드하면 AI가 분석해 핵심 항목을 요약하고 리스크까지 검증합니다.
- **3단계 — 일정 캘린더:** 공고·제안 마감 일정을 캘린더로 한눈에 볼 수 있게 합니다.

### 기대 효과
반복적인 정보 수집·정리는 AI가 맡고, 영업 담당자는 고객과 사업에 대한 판단에 시간을 씁니다. 공고 누락을 줄이고, RFP 검토 시간을 줄이고, 근거 있는 Go / No-Go 결정을 더 빨리 내리는 것이 목표입니다.
