## RFP Insight AI

**금융기관 IT 입찰공고, 놓치지 않고 빠르게 읽는다**

금융기관의 IT 사업 공고를 매일 모니터링하고, 제안요청서(RFP)를 분석해 리스크까지 검증하며, 설명회·마감 일정을 캘린더로 한눈에 보여주는 영업 지원 서비스입니다.

### 해결하려는 문제
- 영업 담당자가 나라장터와 기관별 사이트를 매일 직접 돌며 새 공고를 확인해야 합니다.
- 재공고·정정공고는 눈에 잘 띄지 않아 대응 타이밍을 놓치기 쉽습니다.
- 긴 RFP에서 범위·예산·자격·평가 기준과 불리한 계약 조건을 찾아 참여 여부를 정하기까지 시간이 오래 걸립니다.

### 대상
- **사용자:** 금융기관 사업을 담당하는 SI·솔루션 영업 담당자
- **모니터링 기관:** 한국은행, 예금보험공사, 신용보증기금, 기술보증기금, 한국주택금융공사, IBK기업은행, 한국산업은행 + 시중은행으로 확대

### 바로 써볼 수 있는 기능
1. **공고 모니터링** — 공고를 마감 임박순으로 보여주고, 공공 금융기관/시중은행 구분, 신규·재공고·정정 필터, 검색, 정렬(마감·최신·예산·판단 지표)을 제공합니다. 공고를 누르면 RFP 요약과 리스크 검증 결과가 열립니다.
2. **RFP 분석 · 리스크 검증** — PDF·TXT 파일을 올리거나 본문을 붙여넣으면 예산, 사업 기간, 제출 마감, 평가 배점, 사업 범위, 참가 자격을 추출합니다. 지체상금률, 추가 비용 없는 과업 변경, 공동수급·하도급 제한, 무상 하자보수 기간, 산출물 권리 귀속, 실적 요건, 마감 임박 등 **12종 규칙**으로 리스크를 검증하고 근거 문장을 함께 보여줍니다. 자사 역량 키워드 일치도와 함께 **Go / 검토 필요 / No-Go** 참고 지표를 계산합니다.
3. **일정 캘린더** — 공고 게시, 제안 설명회, 제출 마감을 월간 캘린더와 14일 일정 목록으로 보여주고, 일정을 누르면 공고 상세로 이동합니다.

> 체험 경로: **RFP 분석 → ‘샘플 RFP 불러오기’** 를 누르면 바로 분석 결과를 볼 수 있습니다.
> 화면의 공고와 RFP는 기능 시연을 위한 **가상 샘플 데이터**입니다.

### 구성
- 정적 웹(HTML·CSS·JS) + 브라우저 내 분석 엔진(`assets/analyzer.js`), PDF 텍스트 추출은 pdf.js 사용 — 별도 서버 없이 동작
- 분석 엔진 단위 테스트: `node --test tests/*.test.js`
- GitHub `main` 브랜치 push 시 Vercel 자동 배포
- 데일리 수집 결과는 담당자 PC에 보관하는 구조로 설계

### 로드맵
- **현재(MVP):** 공고 모니터링 화면, RFP 분석·리스크 검증 엔진, 일정 캘린더
- **1단계 — 공고 자동 수집:** 데일리로 확인하는 공고를 자동 수집하고 시중은행 공고까지 확대
- **2단계 — AI 분석 고도화:** LLM을 연동해 RFP 요약 품질과 리스크 검증 범위 확대
- **3단계 — 일정 관리 확장:** 업무 캘린더 연동, 마감 리마인드

### 기대 효과
반복적인 정보 수집·정리는 AI가 맡고, 영업 담당자는 고객과 사업에 대한 판단에 시간을 씁니다. 공고 누락을 줄이고, RFP 검토 시간을 줄이고, 근거 있는 Go / No-Go 결정을 더 빨리 내리는 것이 목표입니다.
